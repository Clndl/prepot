# Writing

Lead with the concrete thing, write for a named audience, and cut anything that sounds templated.

## Modes

| Request | Mode | Read |
|---|---|---|
| Article, guide, blog post, tutorial, newsletter | **article** | [article-writing.md](references/article-writing.md) |
| README, API docs, contributing guide, docs from code | **docs** | [documentation-expert.md](references/documentation-expert.md) |

## Rules

- Load only the mode's file.
- Never invent facts, metrics, or biography the sources don't support.

## Done when

The mode's quality gate or checklist passes for the delivered text.
